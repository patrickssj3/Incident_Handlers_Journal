# Incident Handler's Journal

A cybersecurity portfolio project completed as part of the **Google Cybersecurity Professional Certificate** (Course 6: *Sound the Alarm: Detection and Response*).

📄 **[View the journal (PDF)](Incident_Handlers_Journal.pdf)**

## Overview

An incident handler's journal is a structured record that security analysts use to document investigations, findings, and the tools used during incident response. Throughout the course, I used this journal to log hands-on labs and incident scenarios, applying the **5 W's** (Who, What, When, Where, Why) and mapping each investigation to the **NIST Incident Response Lifecycle**:

1. Preparation
2. Detection and Analysis
3. Containment, Eradication, and Recovery
4. Post-Incident Activity
